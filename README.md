## The project was intended to be larger, but I am not suited to creating a resource pack. However, I will continue to maintain the Universal Ores and Vanilla textures. 

This Minecraft resource pack adds outlines to ores for the [Universal Ores mod](https://modrinth.com/mod/universal_ores), making them more visible.
It is trying to be compatible with all versions of Minecraft.
